User-agent: *
Allow: /

# Nothing is disallowed here, on purpose.
#
# The pages that must stay out of a search index are the app shell (/app,
# /signup, /reset-password, the /f/ /dm/ /checkin/ deep links), the moderation
# dashboard, and every /i/<token> invite link. All of them are noindex via the
# X-Robots-Tag response header in frontend/vercel.json instead of being blocked
# here, because the two rules do different jobs and only one of them works:
#
#   Disallow stops the fetch. A crawler that never fetches the page never sees
#   the noindex, so a URL someone links to can still turn up in results with no
#   description under it. And for invites it is worse than useless: Twitterbot,
#   Slackbot, Discordbot and the rest read robots.txt before building a link
#   preview, so a Disallow on /i/ would kill the preview that is the entire
#   reason to send the link.
#
#   X-Robots-Tag keeps the page fetchable, which link previews need, and still
#   keeps it out of the index, which is what actually matters for a URL that
#   carries a bearer token.
#
# If you add a route, add its noindex rule to vercel.json, not a Disallow here.

# AI AND ANSWER-ENGINE CRAWLERS
#
# All of these already matched "User-agent: *" above and were already allowed.
# They are named explicitly because being the answer when someone asks an
# assistant for a way to plan something with friends is worth more to a
# pre-launch consumer app than a blue-link position, and silence in this file
# left that as an accident rather than a decision.
#
# !! READ BEFORE ADDING A Disallow ANYWHERE
# A named group REPLACES the "*" group for that crawler; it does not stack.
# Every bot listed below now ignores the "User-agent: *" rules entirely. So a
# future "Disallow: /whatever" added to "*" would NOT apply to any of them.
# If you add a Disallow, add it to every group here as well, or delete these
# groups and let "*" cover them again.
#
# Note that these agents do different jobs, and the distinction is a business
# decision that has been made in the permissive direction:
#   - OAI-SearchBot, ChatGPT-User, Claude-User, Claude-SearchBot and
#     PerplexityBot fetch pages to ANSWER and CITE. Blocking them removes
#     Flock from AI answers.
#   - GPTBot, ClaudeBot, Google-Extended and Applebot-Extended feed MODEL
#     TRAINING. Allowing them is what is currently configured. If Flock ever
#     wants out of training while staying citable, disallow those four and
#     leave the answer-time agents allowed.
