# Python deps for the venue sensor.
#
# NOT PINNED YET. Nothing here is version-locked, so a Pi flashed in two years
# gets whatever pip resolves that day. Once a unit is verified on real hardware,
# run `pip3 freeze > requirements.lock.txt` on that unit, commit it, and have
# setup.sh install from the lock file instead. See README.md, "Pinning".

# IR break-beam on GPIO 17. Correct for the Pi 3, 4 and Zero.
#
# NOT correct for the Pi 5, which moved GPIO behind the RP1 southbridge:
# RPi.GPIO cannot drive it and fails at startup with a message about a
# peripheral base address. `rpi-lgpio` is a drop-in replacement providing the
# same module and API, and setup.sh installs it instead when it sees a Pi 5.
# The two cannot both be installed. This matters because the hardware demo unit
# build plan specifies a Pi 5.
RPi.GPIO

# The thermal camera needs NOTHING here. The FLIR Lepton arrives over USB as a
# V4L2 device and main.py reads it with ioctls from the standard library, on
# purpose: every Python package that reads a UVC camera brings an image
# pipeline with it (OpenCV, Pillow, numpy image IO), and an image pipeline on
# this device is the one thing the published privacy policy says is not here.
# The MLX90640 I2C driver and the Blinka shim it needed are gone with it.

spidev                               # MCP3008 ADC (noise) over SPI
requests                             # HTTPS push to the backend
pygame                               # demo-unit display ONLY; imported lazily, so a
                                     # headless venue unit still runs without it
